## Compuerta mecanizada de transparencia de tres alias

El script `scripts/audit_eight_expanded_aliases.py` genera `SourceToSpecDefeqAudit.lean`, donde los tipos **expandidos** se vuelven a definir a partir de: (i) la interfaz literal para 5.1 y 5.2 y (ii) el cuerpo efectivo de `noSimultaneousInteriorCurrentSpec` para A.1.2, especializando `Type*\to Type 0`. Exige al kernel seis pruebas separadas: tres igualdades definicionales (con `rfl`) y tres teoremas en los tipos explícitos.

**Importante:** que `rfl` pase acredita igualdad de fórmulas y referencias **dentro de Lean**. No acredita que la fórmula capture todas las condiciones del manuscrito; esas comparaciones siguen clasificadas arriba, en particular las tres brechas SOURCE y el dominio A.1.2. Las fórmulas de 5.1 y 5.2 dependen de la elección exacta de norma y de los 36 coeficientes racionales de $F_0$.
